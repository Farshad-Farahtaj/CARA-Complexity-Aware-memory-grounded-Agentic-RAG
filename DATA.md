# Patient Test Data — Source & Structure

## Where the data comes from

Synthetic (not real) patient records from **Synthea**, generated by MITRE, downloaded from:

**HuggingFace dataset:** `mikeee333sisin/100K_tx_synthetic_patient_data`
Page: https://huggingface.co/datasets/mikeee333sisin/100K_tx_synthetic_patient_data

112,411 diverse synthetic patients (Texas population, mixed conditions — not disease-specific).

### Direct download links (each is a separate Parquet file)

| File | Size | Contents |
|---|---|---|
| [patients.parquet](https://huggingface.co/datasets/mikeee333sisin/100K_tx_synthetic_patient_data/resolve/main/patients.parquet?download=true) | 9 MB | Id, FIRST, LAST, BIRTHDATE, GENDER, etc. — one row per patient |
| [conditions.parquet](https://huggingface.co/datasets/mikeee333sisin/100K_tx_synthetic_patient_data/resolve/main/conditions.parquet?download=true) | 111 MB | PATIENT (id), DESCRIPTION — one row per diagnosis, many rows per patient |
| [medications.parquet](https://huggingface.co/datasets/mikeee333sisin/100K_tx_synthetic_patient_data/resolve/main/medications.parquet?download=true) | 252 MB | PATIENT (id), DESCRIPTION — one row per prescription |
| [allergies.parquet](https://huggingface.co/datasets/mikeee333sisin/100K_tx_synthetic_patient_data/resolve/main/allergies.parquet?download=true) | 1.3 MB | PATIENT (id), DESCRIPTION — one row per allergy |

These are NOT committed to this repo (too large, and are raw data, not code). Download them fresh from the links above if needed again; save them locally in a folder such as `Patient Dataset/` (already in `.gitignore`).

## How the test patient was selected and imported

- `find_patient.py` — reads the 4 Parquet files, filters for a patient on a blood-thinner (warfarin) who also has a cardiac condition, and prints their full profile. This is how we picked a realistic, high-risk test case.
- `import_test_patient.py` — takes that same patient, filters out non-clinical Synthea "finding" entries (e.g. employment status, criminal record — social-determinants-of-health noise, not real diagnoses), creates a test clinic ("Riverside General Hospital"), and registers the patient for real in `cara.db` via `database.py`'s `register_clinic` / `register_patient`.
